# 路由与配置

配置文件：`payment-service/src/main/resources/application.yml`

---

## 1. 服务端口与依赖

| 项 | 值 |
|----|-----|
| `server.port` | **8104** |
| MySQL | `MYSQL_JDBC_URL` / `MYSQL_USERNAME` / `MYSQL_PASSWORD` |
| Redis | `REDIS_HOST` / `REDIS_PORT`（回调锁，可选） |
| Billing 基址 | `tokenhub.billing.base-url` ← `TOKENS_GATEWAY_BILLING_URI` |

---

## 2. 对外 API（经网关 `/payments/**`）

网关路由：`payment-payments` → `TOKENS_GATEWAY_PAYMENT_URI`（默认 `http://127.0.0.1:8104`）。

| 方法 | 路径 | 鉴权 | 说明 |
|------|------|------|------|
| POST | `/payments/mock/recharge` | JWT | 同步充值 → `PAID` |
| POST | `/payments/mock/checkout` | JWT | 创建 `INIT` 订单 |
| POST | `/payments/mock/callback` | HMAC | 异步回调入账 |

### 请求示例（recharge）

```http
POST /payments/mock/recharge
Authorization: Bearer <jwt>
Content-Type: application/json

{"amount": 1000}
```

响应信封：`ApiResponse`，`data` 含 `orderNo`、`amount`、`currency`、`status`。

---

## 3. 内部 API（`/internal/payments/**`）

需头：`X-Internal-Token: <BILLING_INTERNAL_TOKEN>`

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/internal/payments/recharge` | 内部充值；可选 `idempotencyKey` 内存幂等 |
| POST | `/internal/payments/orders/retry-credit` | body: `{ "orderNo": "..." }` |
| POST | `/internal/payments/orders/{orderNo}/channel-reconcile` | 查单后入账 |
| POST | `/internal/payments/reconciliation/batches` | CSV 对账导入 |
| GET | `/internal/payments/reconciliation/batches/{id}` | 批次汇总 |

**直连注意**：内部路径不经过网关时，URL 为 `http://127.0.0.1:8104/internal/...`；经网关时需在网关增加 `/internal/payments` 路由（当前默认仅暴露 `/payments/**` 给 C 端）。

---

## 4. 鉴权速查

| 路径前缀 | 机制 |
|----------|------|
| `/internal/**` | `PaymentInternalApiGuardFilter` → `X-Internal-Token` |
| `/payments/**`（除 callback） | `PaymentJwtMvcInterceptor` → `Authorization: Bearer` JWT |
| `/payments/mock/callback` | `MockCallbackSignatureVerifier` |

---

## 5. 环境变量

| 变量 | 默认 | 用途 |
|------|------|------|
| `JWT_SECRET` | `dev-only-change-me-32bytes-minimum!!` | 用户 JWT 验签 |
| `BILLING_INTERNAL_TOKEN` | `dev-internal-token` | 内部 API + 调 billing |
| `MOCK_CALLBACK_SECRET` | `dev-mock-callback-secret-change` | Mock 回调 HMAC |
| `TOKENS_GATEWAY_BILLING_URI` | `http://127.0.0.1:8103` | billing 基址 |
| `PAYMENT_RECONCILE_ENABLED` | `false` | INIT 观测任务 |
| `PAYMENT_RECONCILE_CRON` | `0 */10 * * * ?` | 调度 cron |
| `PAYMENT_RECONCILE_STALE_INIT_WARN_MINUTES` | `60` | stale 阈值 |
| `PAYMENT_CHANNEL_QUERY_MOCK_RETURNS_PAID` | `false` | Mock 查单是否返回 PAID |

## 6. application.yml 摘录

```25:33:payment-service/src/main/resources/application.yml
tokenhub:
  billing:
    base-url: ${TOKENS_GATEWAY_BILLING_URI:http://127.0.0.1:8103}
  payment:
    reconcile-enabled: ${PAYMENT_RECONCILE_ENABLED:false}
    reconcile-cron: ${PAYMENT_RECONCILE_CRON:0 */10 * * * ?}
    reconcile-stale-init-warn-minutes: ${PAYMENT_RECONCILE_STALE_INIT_WARN_MINUTES:60}
    channel-query:
      mock-returns-paid: ${PAYMENT_CHANNEL_QUERY_MOCK_RETURNS_PAID:false}
```

## 8. 本地联调最小集

1. MySQL 已有 `payment_orders`、对账表迁移。
2. `billing-service` 运行且 `BILLING_INTERNAL_TOKEN` 一致。
3. `gateway-service` 将 `/payments/**` 指到 8104。
4. `console-web` 登录后调用 `/payments/mock/recharge`（经网关 `/api` 代理）。
