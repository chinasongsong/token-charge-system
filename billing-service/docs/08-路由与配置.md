# 路由与配置

配置文件：`billing-service/src/main/resources/application.yml`

默认端口：**`8103`**。经网关访问时，客户端只连网关 `8080`，由网关转发到本服务（见 [gateway 08-路由与配置.md](../../gateway-service/docs/08-路由与配置.md)）。

---

## 1. 公开 API（需 JWT）

`BillingJwtMvcInterceptor` 保护；请求头：

```http
Authorization: Bearer <JWT>
```

| 方法 | 路径 | Controller | 说明 |
|------|------|------------|------|
| `POST` | `/apikeys` | `ApiKeyController` | 创建 Key |
| `GET` | `/apikeys` | `ApiKeyController` | 列表 |
| `PATCH` | `/apikeys/{id}` | `ApiKeyController` | 禁用（`status=DISABLED`） |
| `GET` | `/dashboard/summary` | `DashboardController` | 仪表盘 |
| `GET` | `/v1/usage` | `UsageQueryController` | 用量查询 |
| `GET` | `/billing/plans` | `BillingPlanViewController` | 套餐 |
| `POST` | `/billing/recharge` | `BillingRechargeViewController` | 发起充值 |
| `POST` | `/billing/subscribe` | `BillingSubscribeViewController` | 订阅 |
| `GET` | `/billing/orders` | `BillingOrderController` | 订单列表 |
| `GET` | `/billing/account` 等 | `BillingAccountController` | 账户；含 mock-deposit（受开关） |
| `POST` | `/billing/invoices/request` | `BillingInvoiceViewController` | 发票申请 |
| `POST` | `/billing/refund/apply` | `BillingRefundViewController` | 退款申请 |

网关路由：`/apikeys/**`、`/dashboard/**`、`/billing/**`、`/v1/usage` → `TOKENS_GATEWAY_BILLING_URI`（默认 `http://127.0.0.1:8103`）。

---

## 2. 内部 API（需 X-Internal-Token）

`InternalApiGuardFilter` 保护；请求头：

```http
X-Internal-Token: <BILLING_INTERNAL_TOKEN>
```

| 方法 | 路径 | Controller | 说明 |
|------|------|------------|------|
| `GET` | `/internal/api-keys/by-fingerprint/{fingerprint}` | `InternalApiKeyController` | Key 解析（O-5 回落源） |
| `POST` | `/internal/billing/preflight` | `InternalBillingController` | 余额 &gt; 0 预检 |
| `POST` | `/internal/billing/credit` | `InternalBillingController` | 幂等入账（payment） |
| `POST` | `/internal/billing/settle` | `InternalBillingController` | 按量结算（O-1/O-2） |
| `POST` | `/internal/billing/reserve` | `InternalBillingController` | 预占（O-3） |
| `POST` | `/internal/billing/reservations/commit` | `InternalBillingController` | 冲正 commit |
| `POST` | `/internal/billing/reservations/release` | `InternalBillingController` | 释放预占 |

**无 JWT**；勿将内部路径暴露到公网。

---

## 3. 鉴权与路径关系速查

| 路径 | Internal Token | JWT |
|------|----------------|-----|
| `/internal/**` | 必需 | 排除 |
| `/apikeys`、`/dashboard/**`、`/billing/**`、`/v1/usage` | 不适用 | 必需 |
| 其它（若有） | 不适用 | 无（当前仓库未使用） |

## 4. 数据源与 Redis

```4:16:billing-service/src/main/resources/application.yml
server:
  port: 8103
spring:
  datasource:
    url: ${MYSQL_JDBC_URL:jdbc:mysql://127.0.0.1:3306/token_charge?...}
  data:
    redis:
      host: ${REDIS_HOST:127.0.0.1}
      port: ${REDIS_PORT:6379}
```

| 依赖 | 用途 |
|------|------|
| MySQL | 余额、订单、Key、预占、Outbox |
| Redis | O-1 `RedisBalanceLock`（可选）；非 O-5 余额缓存 |

## 6. tokenhub.billing 业务配置

```29:52:billing-service/src/main/resources/application.yml
tokenhub:
  billing:
    allow-mock-deposit: ${ALLOW_MOCK_DEPOSIT:false}
    reconciliation-enabled: ${BILLING_RECONCILIATION_ENABLED:false}
    reconciliation-cron: ${BILLING_RECONCILIATION_CRON:0 0 3 * * ?}
    reconciliation-stale-pending-hours: ${BILLING_RECONCILIATION_STALE_PENDING_HOURS:1}
    balance-lock:
      enabled: ${BILLING_BALANCE_LOCK_ENABLED:false}
      ttl-ms: ${BILLING_BALANCE_LOCK_TTL_MS:5000}
      max-wait-ms: ${BILLING_BALANCE_LOCK_MAX_WAIT_MS:1500}
      spin-sleep-ms: ${BILLING_BALANCE_LOCK_SPIN_SLEEP_MS:30}
    outbox:
      enabled: ${BILLING_OUTBOX_ENABLED:false}
      fixed-delay-ms: ${BILLING_OUTBOX_FIXED_DELAY_MS:2000}
      batch-size: ${BILLING_OUTBOX_BATCH_SIZE:50}
      max-attempts: ${BILLING_OUTBOX_MAX_ATTEMPTS:8}
      backoff-base-seconds: ${BILLING_OUTBOX_BACKOFF_BASE_SECONDS:30}
    reservation:
      default-ttl-seconds: ${BILLING_RESERVATION_TTL_SECONDS:120}
    apikey-expiration:
      enabled: ${BILLING_APIKEY_EXPIRATION_ENABLED:false}
      cron: ${BILLING_APIKEY_EXPIRATION_CRON:0 */5 * * * ?}
  payment:
    base-url: ${TOKENS_GATEWAY_PAYMENT_URI:http://127.0.0.1:8104}
```

## 8. 本地联调最小环境变量

| 变量 | 用途 |
|------|------|
| `MYSQL_JDBC_URL` / `MYSQL_USERNAME` / `MYSQL_PASSWORD` | 账务库 |
| `JWT_SECRET` | 控制台 API |
| `BILLING_INTERNAL_TOKEN` | 网关 / adapter 调内部 API |
| `REDIS_HOST` / `REDIS_PORT` | 开启 O-1 锁时建议配置 |
| `BILLING_BALANCE_LOCK_ENABLED` | 压测后按需 `true` |
| `BILLING_OUTBOX_ENABLED` | 与 MQ 阶段同步开启 |
