## 2. 公开路由判定

```17:25:console-web/src/router/index.ts
function isPublicRoute(path: string): boolean {
  if (path === "/" || path === "/experience") {
    return true;
  }
  if (path.startsWith("/login") || path.startsWith("/register")) {
    return true;
  }
  return false;
}
```

公开路由 **不** 检查 token；控制台子路径 **必须** 有 token。

## 3. 全局前置守卫

```59:72:console-web/src/router/index.ts
router.beforeEach((to) => {
  const session = useSessionStore();
  const token =
    session.accessToken || (typeof localStorage !== "undefined" ? localStorage.getItem("accessToken") : null);
  const isConsole = to.path === ROUTE_CONSOLE_PREFIX || to.path.startsWith(`${ROUTE_CONSOLE_PREFIX}/`);
  const pathOnly = to.path.split("?")[0] ?? to.path;
  if (isPublicRoute(pathOnly)) {
    return true;
  }
  if (isConsole && !token) {
    return { path: "/login", query: { redirect: to.fullPath } };
  }
  return true;
});
```

行为：

1. 公开路径 → 放行。
2. 访问 `/console/**` 且无 token → 跳转 `/login?redirect=<原路径>`。
3. 其它路径（当前无）→ 放行。

**双读 token**：优先 Pinia `session.accessToken`，回退 `localStorage`（避免刷新后 store 未水合时误判）。

## 4. 登录后回跳

`LoginView` 在成功登录后：

```typescript
const redir = typeof route.query.redirect === "string" ? route.query.redirect : "";
await router.push(redir && redir.startsWith("/") ? redir : "/console/dashboard");
```

仅接受以 `/` 开头的 `redirect`，降低开放重定向风险。

---

## 5. 鉴权与 API 的关系

| 层 | 职责 |
|----|------|
| Router | 阻止未登录用户**进入**控制台页面 |
| `api/client.ts` | 请求自动带 `Authorization: Bearer` |
| 后端 | 各服务校验 JWT（最终权威） |

前端守卫可被绕过（直接调 API），**不能**替代服务端鉴权。

## 6. Shell 布局

`ShellView` 使用 `el-menu` 的 `router` 模式，`default-active` 绑定当前 `route.path`。子页面通过 `<router-view />` 渲染在右侧主区。
