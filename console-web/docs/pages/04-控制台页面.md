# 控制台页面

页面位于 `console-web/src/views/`，控制台子路由挂载在 `ShellView` 下。

---

## 1. 公开页

### LandingView (`/`)

营销落地页，顶栏 `SiteTopNav` 可跳转登录/控制台。

### ExperienceView (`/experience`)

**模型体验**：不强制登录。

| 能力 | API |
|------|-----|
| 拉模型列表 | `fetchModels({ preferApiKey })` |
| 对话 | `chatCompletions` |
| 填入平台 Key | `setExperienceSk` → sessionStorage |

Bearer 策略见 [02-API客户端.md](./02-API客户端.md)。适合演示 `sk_*` 调用 `/v1/chat/completions`。

### LoginView / RegisterView

| 页面 | API | 成功后 |
|------|-----|--------|
| 登录 | `POST /user/login` | `session.setToken`，跳转 `redirect` 或 dashboard |
| 注册 | `POST /user/register` | 提示成功，引导登录 |

支持 `?email=` 预填（注册→登录链路）。

## 2. 控制台壳 ShellView

路径：`/console/**` 父组件。

侧栏菜单：

| 菜单 | 路由 | 图标 |
|------|------|------|
| 总览 | `/console/dashboard` | Odometer |
| KEY 管理 | `/console/api-keys` | Key |
| 账户充值 | `/console/recharge` | CreditCard |
| 账单订单 | `/console/recharge-records` | List |
| 用量明细 | `/console/usage` | Histogram |
| 工单中心 | `/console/support` | Tickets |

---

## 3. DashboardView

**总览卡片**：`GET /dashboard/summary`（余额、今日用量等）。

**列表区**（并行加载）：

| 数据 | API |
|------|-----|
| 最近 API Key | `GET /apikeys` |
| 最近订单 | `GET /billing/orders?limit=10` |
| 最近用量 | `GET /v1/usage?limit=10` |

用量走 OpenAI 兼容路径，仍经 `apiJson` 若 billing 封装了信封（与 adapter 返回格式一致时由后端约定）。

---

## 4. ApiKeysView

| 操作 | API |
|------|-----|
| 列表 | `GET /apikeys` |
| 创建 | `POST /apikeys` → 展示 **一次性** `plaintextKey` |
| 禁用/删除 | `DELETE /apikeys/:id` 等（以实现为准） |

创建后需用户自行保存 Key；前端不持久化明文。

---

## 5. RechargeView

**Mock 充值**：

```http
POST /payments/mock/recharge
{ "amount": <number> }
```

对应 payment-service 同步入账（`payRecharge` → `PAID`）。

**套餐列表**：`GET /billing/plans`；**订阅**：`POST /billing/subscribe`（带确认框）。

---

## 6. BillingOrdersView

`GET /billing/orders?limit=100` — 展示扣费/账务订单记录（与充值订单区分：后者在 payment 表，前者为 billing 消费流水）。

---

## 7. UsageDetailView

`GET /v1/usage?limit=100` — Token 用量明细表。

---

## 8. SupportView

工单系统（user-center）：

| 操作 | API |
|------|-----|
| 列表 | `GET /user/support/tickets` |
| 新建 | `POST /user/support/tickets` |
| 消息 | `GET/POST .../tickets/:id/messages` |

---

## 9. 共享组件

| 组件 | 作用 |
|------|------|
| `SiteTopNav.vue` | 顶栏；已登录时 `GET /user/me` 展示昵称 |
| `AuthBrandPanel.vue` | 登录/注册品牌侧栏 |
| `FloatingHelp.vue` | 帮助入口 |

---

## 10. 错误与加载态

各 View 普遍模式：

- `ref` loading 标志 + `try/catch`；
- `ElMessage` / `ElMessageBox` 提示；
- 表格 `v-loading`。

`apiJson` 抛出的 `Error.message` 直接展示给用户。
