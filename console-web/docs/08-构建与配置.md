## 1. 脚本（package.json）

|------|------|

## 2. Vite 配置

文件：`console-web/vite.config.ts`

```4:15:console-web/vite.config.ts
export default defineConfig({
  plugins: [vue()],
  server: {
    port: 5173,
    proxy: {
      "/api": {
        target: "http://127.0.0.1:8080",
        changeOrigin: true,
        rewrite: (p) => p.replace(/^\/api/, ""),
      },
    },
  },
});
```

| 项 | 说明 |
|----|------|
| 浏览器请求 | `http://localhost:5173/api/user/login` |
| 转发到网关 | `http://127.0.0.1:8080/user/login` |
| `rewrite` | 去掉前缀 `/api` |

因此开发时 **`VITE_API_BASE=/api`**，与生产「同域反代 /api」模式一致。

---

## 3. 环境变量

### .env.development

```env
VITE_API_BASE=/api
```

| 变量 | 必填 | 说明 |
|------|------|------|
| `VITE_API_BASE` | 否 | API 前缀；空字符串表示与页面同域根路径 |

### 生产示例

部署静态资源到 CDN 或 Nginx 时，由反向代理将 `/api` 转到 gateway：

```nginx
location /api/ {
  proxy_pass http://gateway:8080/;
}
```

构建：

```bash
VITE_API_BASE=/api npm run build
```

产物目录：`dist/`。

| 1 | 启动 MySQL、Redis（若网关限流/缓存需要） |
