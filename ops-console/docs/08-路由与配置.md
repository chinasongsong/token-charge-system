# 路由与配置

配置文件：`ops-console/src/main/resources/application.yml`

---

## 1. 服务端口

| 项 | 值 |
|----|-----|
| `server.port` | **8105** |
| `spring.application.name` | `ops-console` |

---

## 2. 网关路由

在 `gateway-service` 中：

| id | Path | 下游 |
|----|------|------|
| `ops-console` | `/ops/**` | `TOKENS_GATEWAY_OPS_URI`（默认 `http://127.0.0.1:8105`） |

网关对 `/ops/**` **不**做 JWT/API Key 解析，仅 Trace；**令牌校验在 ops-console 进程内**。

---

## 3. API 一览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/ops/model-providers` | 模型供应商列表 |
| GET | `/ops/audit-events?limit=` | 审计事件 |

公共请求头：

```http
X-Ops-Token: <OPS_INTERNAL_TOKEN>
```

---

## 4. 数据源

```7:11:ops-console/src/main/resources/application.yml
  datasource:
    url: ${MYSQL_JDBC_URL:jdbc:mysql://127.0.0.1:3306/token_charge?...}
    username: ${MYSQL_USERNAME:root}
    password: ${MYSQL_PASSWORD:change-me}
```

与 billing、payment 共用库 `token_charge`（表：`model_providers`、`audit_events`）。

---

## 5. 环境变量

| 变量 | 默认 | 说明 |
|------|------|------|
| `MYSQL_JDBC_URL` | 本地 token_charge | JDBC URL |
| `MYSQL_USERNAME` | `root` | 数据库用户 |
| `MYSQL_PASSWORD` | `change-me` | 数据库密码 |
| `OPS_INTERNAL_TOKEN` | `dev-ops-token` | 映射 `tokenhub.ops.internal-token` |
| `TOKENS_GATEWAY_OPS_URI` | `http://127.0.0.1:8105` | 网关下游（网关侧配置） |

```13:15:ops-console/src/main/resources/application.yml
tokenhub:
  ops:
    internal-token: ${OPS_INTERNAL_TOKEN:dev-ops-token}
```

---

## 7. 本地 curl 示例

```bash
# 直连
curl -s -H "X-Ops-Token: dev-ops-token" http://127.0.0.1:8105/ops/model-providers

# 经网关（需 gateway 与 OPS URI 正确）
curl -s -H "X-Ops-Token: dev-ops-token" http://127.0.0.1:8080/ops/audit-events?limit=20
```
