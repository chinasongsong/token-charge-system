# 路由与配置

配置文件：`user-center-service/src/main/resources/application.yml`

对外访问通常经 **gateway `8080`**，路径不变（`/user/**` → 转发至本服务 `8101`）。

---

## 1. 服务与数据源

```1:21:user-center-service/src/main/resources/application.yml
server:
  port: 8101

spring:
  application:
    name: user-center-service
  datasource:
    url: ${MYSQL_JDBC_URL:jdbc:mysql://127.0.0.1:3306/token_charge?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai}
    username: ${MYSQL_USERNAME:root}
    password: ${MYSQL_PASSWORD:change-me}
    driver-class-name: com.mysql.cj.jdbc.Driver
...
tokenhub:
  jwt:
    issuer: user-center
    secret: ${JWT_SECRET:dev-only-change-me-32bytes-minimum!!}
    ttl-seconds: 86400
```

| 项 | 默认 | 说明 |
|----|------|------|
| `server.port` | `8101` | 直连调试端口 |
| `MYSQL_JDBC_URL` | 本地 `token_charge` | 须已执行 `deploy/sql` 迁移 |
| `MYSQL_USERNAME` / `MYSQL_PASSWORD` | `root` / `change-me` | 生产用密钥注入 |
| `JWT_SECRET` | 开发占位字符串 | **与 gateway 相同**；≥32 字节推荐 |
| `tokenhub.jwt.ttl-seconds` | `86400` | Access token 有效期（秒） |
| `tokenhub.jwt.issuer` | `user-center` | JWT `iss` |

MyBatis-Plus：`map-underscore-to-camel-case: true`。

## 4. API：UserAuthController

基路径：`/user`（`UserAuthController`）

统一响应包装：`ApiResponse<T>`（`common-core`）。

| 方法 | 路径 | 认证 | 请求体 | 响应 `data` |
|------|------|------|--------|-------------|
| `POST` | `/user/register` | 否 | `RegisterRequest`：`email`, `password`(8–128), `displayName?` | `UserProfileResponse`：`id`, `email`, `displayName` |
| `POST` | `/user/login` | 否 | `LoginRequest`：`email`, `password` | `TokenResponse`：`accessToken`, `tokenType`=`Bearer`, `expiresInSeconds` |
| `POST` | `/user/logout` | 否 | 无 | `null`（占位，无服务端吊销） |
| `POST` | `/user/password/forgot` | 否 | `ForgotPasswordRequest`：`email` | `null`（未知邮箱亦成功） |
| `POST` | `/user/password/reset` | 否 | `ResetPasswordRequest`：`email`, `code`(6–16), `newPassword` | `null` |
| `GET` | `/user/me` | **Bearer JWT** | 无 | `UserProfileResponse` |

### 4.1 登录相关请求头

| Header | 用途 |
|--------|------|
| `Authorization` | 仅 `/user/me` 必需：`Bearer <jwt>` |
| `X-Device-Fingerprint` | 可选，写入 `user_devices.fingerprint` |
| `User-Agent` | 可选，写入 `user_devices.user_agent` |
| `X-Forwarded-For` | 经网关时取首段 IP；否则 `remoteAddr` |

### 4.2 示例

```http
POST /user/login HTTP/1.1
Host: localhost:8080
Content-Type: application/json
X-Device-Fingerprint: fp-abc-123

{"email":"user@example.com","password":"password12"}
```

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "tokenType": "Bearer",
    "expiresInSeconds": 86400
  }
}
```

## 5. API：SupportTicketController

基路径：`/user/support/tickets`（全部需 **Bearer JWT**）

| 方法 | 路径 | 请求体 | 响应 `data` |
|------|------|--------|-------------|
| `GET` | `/user/support/tickets` | 无 | `List<SupportTicketItem>` |
| `POST` | `/user/support/tickets` | `SupportTicketCreateRequest`：`title`（非空，trim） | `SupportTicketItem` |
| `GET` | `/user/support/tickets/{ticketId}/messages` | 无 | `List<SupportTicketMessageItem>` |
| `POST` | `/user/support/tickets/{ticketId}/messages` | `SupportTicketReplyRequest`：`body`（非空，trim） | `SupportTicketMessageItem` |

### 5.1 DTO 字段摘要

**SupportTicketItem**：`id`, `title`, `status`, `priority`, `createdAt`, `updatedAt`

**SupportTicketMessageItem**：`id`, `ticketId`, `userId`, `role`, `body`, `createdAt`

### 5.2 示例

```http
GET /user/support/tickets HTTP/1.1
Host: localhost:8080
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

## 6. 常见错误码（业务层）

由 `BusinessException` + 全局处理返回（具体 JSON 结构见 `common-core`）：

| 场景 | ErrorCode | 典型 message |
|------|-----------|--------------|
| 未登录 / JWT 无效 | `UNAUTHORIZED` | 未登录或令牌无效 |
| 登录失败 | `UNAUTHORIZED` | 邮箱或密码错误 |
| 邮箱已注册 | `CONFLICT` | 邮箱已注册 |
| 参数校验 | `BAD_REQUEST` | 邮箱格式不正确 / 密码长度至少 8 位 |
| 重置码错误 | `BAD_REQUEST` | 验证码无效或已过期 |
| 工单不存在或非本人 | `NOT_FOUND` | 工单不存在 |
| 用户不存在（/me） | `NOT_FOUND` | 用户不存在 |

## 8. 本地联调最小环境变量

| 变量 | 用途 |
|------|------|
| `MYSQL_JDBC_URL` / `MYSQL_USERNAME` / `MYSQL_PASSWORD` | 数据库 |
| `JWT_SECRET` | 签发与验签；与 gateway 一致 |
| `TOKENS_GATEWAY_USER_URI` | 网关转发目标（默认 `http://127.0.0.1:8101`） |

启动顺序建议：MySQL（已跑 SQL）→ `user-center-service:8101` → `gateway-service:8080`。

---

## 9. 业界部署方案对比

| 方案 | 适用 |
|------|------|
| **单实例 + 直连 8101** | 本地开发 |
| **网关统一入口（当前）** | 前后端只记一个 origin |
| **K8s Service `user-center-service`** | 网关 URI 改为集群 DNS |
| **独立 IAM 服务** | 多产品共用账户时迁出 user-center |

演进建议：将 `TOKENS_GATEWAY_USER_URI` 改为服务发现地址；敏感配置走 Secret 管理，禁止提交默认 `JWT_SECRET`。
