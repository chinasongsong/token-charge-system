# 路由与配置

配置文件：`gateway-service/src/main/resources/application.yml`

---

## 1. 路由表

Spring Cloud Gateway 按**声明顺序**匹配第一条满足 `predicates` 的路由。

| id | Path | 下游 URI（环境变量） | 默认端口 |
|----|------|----------------------|----------|
| `billing-v1-usage` | `/v1/usage` | `TOKENS_GATEWAY_BILLING_URI` | 8103 |
| `billing-apikeys` | `/apikeys`, `/apikeys/**` | 同上 | 8103 |
| `billing-dashboard` | `/dashboard/**` | 同上 | 8103 |
| `billing-account-orders` | `/billing/**` | 同上 | 8103 |
| `payment-payments` | `/payments/**` | `TOKENS_GATEWAY_PAYMENT_URI` | 8104 |
| `ops-console` | `/ops/**` | `TOKENS_GATEWAY_OPS_URI` | 8105 |
| `adapter-v1` | `/v1/**` | `TOKENS_GATEWAY_ADAPTER_URI` | 8102 |
| `user-center` | `/user/**` | `TOKENS_GATEWAY_USER_URI` | 8101 |

**关键**：`/v1/usage` 必须在 `/v1/**` **之前**，否则用量接口会被转到 adapter。

```17:49:gateway-service/src/main/resources/application.yml
        # 更具体的路由须写在 /v1/** 之前
        - id: billing-v1-usage
          uri: ${TOKENS_GATEWAY_BILLING_URI:http://127.0.0.1:8103}
          predicates:
            - Path=/v1/usage
        ...
        - id: adapter-v1
          uri: ${TOKENS_GATEWAY_ADAPTER_URI:http://127.0.0.1:8102}
          predicates:
            - Path=/v1/**
```

## 2. 路径与过滤器关系速查

| 路径 | 路由目标 | 典型过滤器参与 |
|------|----------|----------------|
| `POST /v1/chat/completions` | adapter | Trace → 鉴权 → Key → 风控* → 限流 → **预检** |
| `POST /v1/embeddings` 等 | adapter | 无预检（非 chat 路径） |
| `GET /v1/models` | adapter | 鉴权 + Key；限流仅 POST |
| `GET /v1/usage` | billing | 鉴权；无 adapter 预检 |
| `POST /user/register` | user-center | 仅 Trace |

\* 风控默认 `risk.enabled=false`

## 3. HTTP 客户端超时

```50:53:gateway-service/src/main/resources/application.yml
      httpclient:
        connect-timeout: 15000
        response-timeout: ${TOKENS_GATEWAY_RESPONSE_TIMEOUT:600000}
```

| 项 | 值 | 说明 |
|----|-----|------|
| `connect-timeout` | 15000 ms | 建立连接超时 |
| `response-timeout` | 默认 600000 ms（10 分钟） | 适合流式 Chat；可按环境调小 |

流式响应期间，网关与客户端、网关与 adapter 连接会保持较长时间，**勿**在生产误设为过短。

## 4. Redis


## 8. 本地联调最小环境变量

| 变量 | 用途 |
|------|------|
| `JWT_SECRET` | `/v1` JWT 验签（生产必填） |

| `REDIS_HOST` / `REDIS_PORT` | 限流与可选缓存 |
| `TOKENS_GATEWAY_*_URI` | 各下游基址 |

## 9. 业界路由方案对比

| 方案 | 适用 |
|------|------|
| **YAML 静态路由（当前）** | 服务数少、变更不频 |
| **Spring Cloud Discovery + `lb://`** | 多实例、K8s 服务发现 |
| **K8s Ingress + 独立 Gateway** | 基础设施团队统一入口 |
| **APISIX / Kong 声明式配置** | 多租户插件生态 |

演进建议：下游 URI 从硬编码 host 改为 `lb://billing-service`，配置来自 Nacos/K8s DNS。
