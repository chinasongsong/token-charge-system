## 3. 收口流程（遵守 AGENTS.md）

1. **先设计**：复制 [`docs/TDD/_template/技术设计文档模板.md`](../TDD/_template/技术设计文档模板.md)，在 `docs/TDD/` 下维护/更新对应 `O-xx` 文档；涉及对外契约则改 `docs/openapi/unified-api.yaml`。
2. **再落代码**：按 `docs/architecture/LAYERS.md` 分层；提交前 `python scripts/check_boundaries.py` 与 `python scripts/gc_scan.py`。
3. **安全与架构**：涉及鉴权/密钥/支付同步 [`docs/SECURITY.md`](../SECURITY.md)；结构性变更同步 [`ARCHITECTURE.md`](../../ARCHITECTURE.md)、[`LAYERS.md`](./LAYERS.md)。
4. **路线图**：在 `docs/dev-plan.md` §2.3 勾选对应项，并在**阶段收口**时更新根目录 [`PROGRESS.md`](../../PROGRESS.md)。
5. **回写本表**：合并后把上表「当前状态」改为 **已交付**（或挂起并注明原因），并在对应 TDD 文末增加「实现对照」小节（服务类名、配置开关、迁移脚本路径）。
